macOS 설치 안내

macOS 12 이상에서 사용할 수 있습니다. DMG를 열고 TeamConsole을 Applications 폴더로 옮겨 주세요.

이번 Mac 배포본은 Apple 공증 전입니다. 처음 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안 → ‘그래도 열기’를 선택해 주세요. Apple 안내

앱의 ‘설치·로그인 도우미’에서 보조 도구와 Claude·Codex를 준비할 수 있습니다. Homebrew가 없다면 Homebrew를 먼저 설치해 주세요.

새 버전이 나오면 앱에서 ‘업데이트하고 다시 시작’을 선택할 수 있습니다. 기존 프로젝트·계정과 실행 중인 세션은 유지됩니다.

Mac 0.28.0에서 처음 업데이트할 때만 설치 후 앱을 한 번 직접 닫고 다시 열어 주세요. 0.28.1부터는 자동으로 다시 시작합니다.
